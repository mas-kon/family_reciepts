# Семейные расходы

[English](README.md) | **Русский**

Telegram-бот для семейной группы и веб-интерфейс для учёта расходов.

Купили что-то, сфотографировали чек, отправили в группу. Бот читает QR-код чека, отдаёт фото нейросети, получает список покупок с категориями и записывает в базу. В вебе видно, кто, что, где и на что тратит. Там же оригинал чека для проверки.

## Возможности

**Запись трат**

- **Чек по фото** или файлом, включая HEIC с айфона. Скидки и залог за тару учитываются отдельными строками.
- **Электронные чеки**: PDF-чек, скриншот онлайн-заказа или доставки, письмо с чеком на отдельную почту.
- **Фискальный QR болгарского чека** даёт точные дату и сумму, защищает от повторной записи и помогает выпрямить фото, снятое боком. Картинку без QR (например, скриншот из приложения магазина) бот тоже узнаёт как повтор: та же сумма в пределах 30 минут и тот же магазин, либо та же сумма в пределах 10 минут под любым названием.
- **Сверка сумм.** Если позиции не сходятся с итогом или с QR, чек помечается «Проверить» с объяснением.
- **Трата текстом**: `+ такси 12`, `/add кофе 3.50`. Можно одной суммой, `+ 12`, тогда запись попадёт в «Без категории».
- **Трата голосом**: «двенадцать евро такси».
- **Доходы**: зарплата, подработка, возвраты. Вносятся командой `/income зарплата 1500`, в вебе, из выписки, по SMS банка о поступлении или регулярным поступлением. Считаются отдельно от расходов, в статистике виден остаток.
- **Переводы внутри семьи** не считаются ни расходом, ни доходом. Карманные деньги ребёнку не учитываются дважды: при переводе и когда ребёнок их тратит. Достаточно один раз указать, как банк пишет имя ребёнка.
- **Банковские уведомления.** Пересланное в группу SMS или push о списании или поступлении превращается в запись.
- **Выписка из банка** в CSV или PDF показывает в вебе расходы и доходы, которые ещё не записаны. PDF-выписку можно прислать и в бот: он перечислит незаписанное и запишет по кнопке. Выписку можно удалить целиком.
- **Трата за другого члена семьи**: `+ Маша: кино 12`, подпись к фото `Маша: тетради`, голосом «Маше на кино 15». Детей без Telegram добавляют в вебе: Настройки → Семья.
- **Регулярные платежи и поступления**: аренда, интернет, подписки, зарплата записываются сами в нужный день.
- **Только евро.** Если в чеке цены в двух валютах, берутся суммы в евро.

**Правка**

- **Из бота**: ответьте на сообщение бота о записи. Текст станет описанием, число новой суммой, а `Маша:` перенесёт трату на Машу. Под каждой записью кнопка «Удалить».
- **В вебе**: магазин, дата, итог, описание, кто потратил, позиции, их категории и гарантия. Удаление с подтверждением.
- **Запоминание категорий.** Исправили категорию товара, и она применится к этому товару во всех чеках и будущих покупках.

**Анализ**

- **Статистика** по категориям, людям, месяцам и магазинам, список чеков с фильтрами, экспорт в CSV.
- **Вопросы обычным языком** в вебе: «сколько ушло на кафе за лето?».
- **Бюджеты по категориям.** Бот предупреждает в группе при 80% и при превышении.
- **Месячный отчёт** с графиком и коротким комментарием нейросети приходит в группу 1-го числа. Если сервис в это время не работал, отчёт уйдёт при следующем запуске. Чек, обработку которого прервал перезапуск, помечается как ошибочный, его можно распознать заново в вебе.
- **Динамика цен.** Одинаковые товары с разными названиями в разных магазинах склеиваются в один.
- **Гарантии.** Бот напоминает, когда у техники заканчивается гарантия.

## Шпаргалка по боту

| Что прислать в группу | Что будет |
|---|---|
| Фото чека | Чек распознан и записан. Подпись к фото станет описанием |
| Фото с подписью `Маша: тетради` | Чек записан на Машу с описанием «тетради» |
| PDF-чек, скриншот заказа | Распознан как обычный чек |
| PDF-выписка из банка | Список незаписанных расходов, доходов и переводов в семье, кнопки «Записать» и потом «Удалить всю выписку» |
| `/income зарплата 1500` | Доход 1500 € в категории «Зарплата» |
| `/income Маша: подработка 200` | Доход записан на Машу |
| `+ такси 12` или `/add такси 12` | Трата 12 € в категории «Такси» |
| `+ 12` | Трата 12 € без описания, в «Без категории» |
| `+ Маша: кино 12` | Трата записана на Машу |
| Голосовое «двенадцать евро такси» | Трата 12 € на такси |
| Пересланное SMS банка | Расход, доход или перевод в семье записан, или бот скажет, что он уже есть |
| `/bank текст` или ответ `/bank` на сообщение | То же для текста, который бот не узнал сам |
| Ответ на сообщение бота текстом | Описание записи |
| Ответ на сообщение бота числом | Новая сумма записи из одной строки |
| Ответ на сообщение бота `Маша:` | Трата перенесена на Машу |
| `/help` | Подсказка |
| `/chatid` | ID группы для настройки |

Все суммы в евро.

## Установка

Нужен Docker с Compose. Для запуска без Docker нужны [uv](https://docs.astral.sh/uv/) и Node.js 20 или новее.

### 1. Бот в Telegram

1. В [@BotFather](https://t.me/BotFather) создайте бота командой `/newbot` и сохраните токен.
2. Там же выполните `/setprivacy`, выберите бота и **Disable**. Иначе бот не увидит фото и голосовые в группе.
3. Добавьте бота в семейную группу и напишите в ней `/chatid`. Бот ответит ID группы. Эта команда работает и до настройки. Пока `ALLOWED_CHAT_IDS` пуст, бот отвечает только на `/chatid` и игнорирует остальные чаты (открытым для всех он остаётся лишь при `AUTH_DISABLED=true`).

### 2. Ключ нейросети

Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai), создайте ключ и пополните баланс на несколько долларов. Какие модели для чего и как экономить, описано ниже в разделе «Нейросеть».

### 3. Настройка

```bash
cp .env.example.ru .env   # или .env.example, там те же настройки с комментариями на английском
# впишите BOT_TOKEN, ALLOWED_CHAT_IDS, LLM_API_KEY, SECRET_KEY и WEB_PASSWORD
# (SECRET_KEY оставлен change-me или пуст: один раз создаётся случайный ключ в data/.secret_key)
# WEB_BIND=127.0.0.1 публикует порт только на этой машине, для реверс-прокси, который стоит здесь же
```

### 4. Запуск в Docker

```bash
docker compose up -d --build
```

Веб откроется на `http://адрес-сервера:8000`, порт берётся из `WEB_PORT`. База и фото чеков лежат в папке `data/` рядом с проектом. Миграции базы применяются при старте автоматически.

```bash
docker compose logs -f              # логи
docker compose restart              # после правки .env
docker compose up -d --build        # после обновления кода
docker compose down                 # остановить
```

Контейнер перезапускается сам после сбоя и после перезагрузки машины.

### 5. Почта для электронных чеков (по желанию)

1. Заведите отдельный ящик, например в Gmail. Для Gmail включите двухэтапную проверку и создайте «пароль приложения», обычный пароль не подойдёт.
2. Впишите в `.env` `IMAP_HOST`, `IMAP_USER` и `IMAP_PASSWORD`, затем `docker compose restart`.
3. В вебе в Настройки → Семья укажите у каждого человека все его адреса, например личный и рабочий: каждый адрес отдельно, через Enter. Чек, пересланный с любого из них, запишется на этого человека. Письмо с незнакомого адреса тоже обработается, но без владельца.

Бот проверяет ящик раз в `IMAP_POLL_MINUTES` минут и пишет о каждом чеке в группу. Письмо помечается прочитанным только после обработки, поэтому сбой его не теряет; каждое вложение читается как отдельный чек.

### Запуск без Docker

```bash
cd frontend && npm ci && npm run build && cd ..
cd backend && uv sync && uv run python -m app.main
```

Для автозапуска без Docker есть юнит systemd в `deploy/check-bot.service`. Одновременно запускайте что-то одно: два экземпляра бота будут мешать друг другу получать сообщения.

## Вход в веб

- **Через Telegram.** Работает, когда у веба есть домен. В @BotFather выполните `/setdomain` и укажите домен. Пустят только участников группы из `ALLOWED_CHAT_IDS`.
- **По паролю.** Задайте `WEB_PASSWORD`. Подходит, пока домена нет. После 5 неверных попыток за минуту следующие с этого адреса отклоняются до конца минуты.

Для доступа из интернета поставьте перед сервисом reverse proxy с HTTPS, например Caddy:

```
expenses.example.com {
    reverse_proxy localhost:8000
}
```

## Нейросеть

### Модели по задачам

Всё задаётся в `.env`, код менять не нужно. В каждом списке модели перечисляются через запятую. Если первая не ответила или упёрлась в лимит, берётся следующая. Текущие списки видны в вебе: Настройки → Нейросеть.

| Переменная | Задача | Требование к модели | Пусто |
|---|---|---|---|
| `LLM_MODELS` | Чеки по фото, PDF без текста, скриншоты | понимает картинки | обязательна |
| `LLM_STRONG_MODELS` | Повторное чтение чека, если суммы не сошлись | понимает картинки, лучше точнее основной | каскад выключен |
| `LLM_TEXT_MODELS` | Траты текстом, банк, выписки, электронные чеки, комментарий к отчёту, склейка товаров | любая | берётся `LLM_MODELS` |
| `LLM_AUDIO_MODELS` | Голосовые сообщения | понимает звук, например Gemini | голос выключен |
| `LLM_ASK_MODELS` | Вопросы в вебе | поддерживает вызов функций | берётся `LLM_TEXT_MODELS` |

Пример, который проверен на болгарских чеках:

```bash
LLM_MODELS=google/gemini-3.5-flash-lite,google/gemini-3.5-flash,deepseek/deepseek-v4.1-flash
LLM_STRONG_MODELS=google/gemini-3.5-flash,deepseek/deepseek-v4.1-flash
LLM_TEXT_MODELS=google/gemini-3.5-flash-lite,deepseek/deepseek-v4.1-flash
LLM_AUDIO_MODELS=google/gemini-3.5-flash-lite,google/gemini-3.5-flash
```

Другие провайдеры, например Gemini напрямую или локальная Ollama, подключаются через `LLM_BASE_URL`. Тогда все задачи идут к одному провайдеру. Примеры есть в `.env.example.ru`.

### Расходы

Чек стоит около 0.1 цента, текстовые задачи ещё дешевле. Для семьи это центы в месяц.

На OpenRouter можно подключить свои ключи провайдеров: Workspace → BYOK. Тогда запросы идут через ваш ключ и ваши лимиты, а с баланса OpenRouter не списывается ничего или 5% комиссии. Но ключ используется только тогда, когда OpenRouter отправляет запрос именно этому провайдеру:

- **Google AI Studio** обслуживает Gemini 3.x. Модели Gemini 2.5 новым пользователям AI Studio недоступны, и OpenRouter отправляет их в Google Vertex за счёт своего баланса. Поэтому в `.env` лучше указывать `google/gemini-3.5-flash-lite` и `google/gemini-3.5-flash`.
- **DeepSeek** как провайдер обслуживает только датированные версии, например `deepseek/deepseek-v4.1-flash-1017`. `deepseek/deepseek-v4.1-flash` без даты обслуживают сторонние провайдеры за счёт баланса OpenRouter. Кроме того, DeepSeek может обучаться на запросах, и OpenRouter не пускает к нему, пока это не разрешено в Settings → Privacy. Разрешать или нет, решать вам.
- **Лимит расходов** на ключ OpenRouter, который стоит в `LLM_API_KEY`, ограничит списания с баланса, например $2 в месяц.

Чем оплачен каждый запрос, видно в вебе: Настройки → Нейросеть.

Учтите условие Google: в Евросоюзе бесплатный доступ к Gemini API формально нельзя использовать для приложения с пользователями. Бесплатные модели других провайдеров могут сохранять запросы.

### Баланс и расход

Вкладка Настройки → Нейросеть собирает всё в одном месте:

- **Баланс OpenRouter**: сколько осталось на счёте, лимит ключа и сколько осталось до него, сколько списано сегодня и за месяц, сколько прошло через ваши ключи.
- **Баланс DeepSeek**, если в `.env` задан `DEEPSEEK_API_KEY`. Ключ нужен только для этого, запросы всё равно идут через `LLM_BASE_URL`.
- **Google AI Studio** баланса не имеет: бесплатный уровень ограничивает число запросов, а не деньги.
- **Расход** за день, 7, 30 или 90 дней: по задачам (чеки, банк, голос, вопросы...), по моделям и провайдерам, по дням. Отдельно списанное с OpenRouter и оплаченное вашими ключами, число ошибок и средняя цена запроса. Каждый запрос к нейросети записывается в таблицу `llm_calls`.

Бот раз в день в 9:30 проверяет баланс и пишет в группу, если на счёте OpenRouter или в лимите ключа осталось меньше `LLM_BALANCE_ALERT` долларов, по умолчанию 1. Об одном и том же низком балансе он напоминает один раз.

### Проверка моделей на своих чеках

```bash
cd backend
uv run python scripts/test_llm.py ~/чек1.jpg ~/чек2.jpg --quiet
uv run python scripts/test_llm.py ~/чек1.jpg --models google/gemini-3.5-flash-lite,deepseek/deepseek-v4.1-flash
```

Скрипт ничего не записывает в базу. Он показывает время ответа, число позиций и сходится ли сумма с итогом и с QR-кодом. Чек, распознанный плохо, можно перераспознать в вебе другой моделью кнопкой «Распознать заново».

## Как работают функции нейросети

**Каскад.** Если сумма позиций не сошлась с итогом или с QR, чек перечитывается моделями из `LLM_STRONG_MODELS`. Если и после этого суммы не сходятся, чек остаётся «Проверить» с пометкой, какой моделью он перечитан.

**Типы записей.** У каждой записи один из трёх типов:

| Тип | Что это | Где учитывается |
|---|---|---|
| Расход | покупка, услуга, комиссия, снятие наличных, перевод человеку вне семьи | статистика, бюджеты, отчёт, вопросы |
| Доход | зарплата, возврат, кэшбэк, деньги от человека вне семьи | отдельная сумма «Доходы» и остаток |
| Внутри семьи | перевод члену семьи или от него | нигде, только в списке записей |

Тип меняется в карточке записи. Переводы между своими счетами и пополнения со своей карты не записываются вовсе.

**Переводы внутри семьи.** В Настройки → Семья, в поле «Имя в банке», укажите, как банк пишет человека: `Vera Maslennikova`. Можно несколько вариантов через запятую. После этого переводы ему и от него, и прошлые, и будущие, считаются переводами внутри семьи. То же самое можно сделать из записи: выберите «Внутри семьи», члена семьи и оставьте галочку «Запомнить». На странице «Выписка» для этого есть тип «Семья: имя».

**Банковские уведомления.** Бот отправляет нейросети только сообщения, где есть сумма в валюте и банковское слово: карта, плащане, покупка, постъпление, превод и подобные. Обычная переписка в нейросеть не уходит. Дальше:
- **Тип.** Нейросеть различает покупку, доход, перевод человеку и движение между своими счетами. Тип записи выбирается по правилам выше.
- **Владелец.** Если последние 4 цифры карты указаны у кого-то в Настройки → Семья, запись делается на этого человека. Иначе на того, кто переслал.
- **Повтор.** Если та же сумма того же типа уже записана в пределах двух дней из другого источника, например расход по чеку, бот только сообщает об этом и ничего не записывает. Другая банковская запись считается той же операцией, только если это тот же магазин в тот же день. Две одинаковые операции за день это две покупки; повторная загрузка той же выписки ничего не записывает дважды. Повторно пересланное уведомление тоже узнаётся.

**Выписка.** Страница «Выписка» в вебе. Загрузите CSV или PDF с текстом, сканы не подходят. Нейросеть находит операции, а сайт показывает тип каждой и какие уже записаны по тем же правилам. Тип строки можно поменять. Ничего не сохраняется, пока вы не нажмёте «Записать». Повторный импорт той же выписки ничего не задвоит.

PDF-выписку можно прислать и в бот. Бот отличает её от чека по IBAN и словам вроде «выписка», «баланс». Он показывает незаписанные расходы, доходы и переводы в семье отдельными группами и записывает всё по кнопке «Записать». Если нужны не все строки, загрузите выписку в вебе. Кнопка живёт до перезапуска бота. Скриншот выписки бот не записывает, присылайте PDF.

**Удаление выписки.** Записи одной выписки связаны между собой. Удалить их разом можно на странице «Выписка» в списке «Загруженные выписки», из списка записей этой выписки или кнопкой «🗑 Удалить всю выписку» под сообщением бота. Другие записи не затрагиваются.

**Категории доходов** выбираются по словам в описании: «зарплата» → «Зарплата», «возврат» → «Возвраты», остальное в «Прочие доходы». Список правится в Настройки → Категории.

**Голосовые.** Нужна `LLM_AUDIO_MODELS`. Голосовые длиннее минуты бот не слушает. Если в сообщении нет речи или это не трата, бот ничего не записывает и молча ставит 🤔. Распознанная фраза сохраняется в описании записи.

**Склейка товаров.** После каждого чека нейросеть в фоне сопоставляет новые названия с уже известными товарами, например «ПРЯСНО МЛЯКО 3% 1Л» и «Мляко прясно Верея 3% 1л» станут «Молоко 3% 1 л». Разные объёмы остаются разными товарами. На странице «Цены» можно отметить товары и объединить их вручную или разделить склеенный товар. Ручные решения автоматическая склейка не трогает.

**Гарантии.** Для техники и бытовых приборов нейросеть берёт гарантийный срок из чека. Если его нет, а вещь дороже 30 €, ставит 24 месяца, минимальную гарантию в ЕС. За `WARRANTY_REMIND_DAYS` дней до конца бот напоминает в группе. Список на странице «Гарантии», срок правится в позиции чека.

**Вопросы.** Нейросеть не видит базу напрямую и не может ничего изменить. Ей доступны только три функции: итоги за период, расходы по месяцам и поиск покупок. Если данных нет, она так и отвечает.

**Комментарий к отчёту.** К месячному отчёту добавляются 2–4 предложения о том, что выросло, что необычно и где превышен бюджет. Если нейросеть недоступна, отчёт приходит без комментария.

## Разработка

```bash
# бэкенд без входа и без бота
cd backend && AUTH_DISABLED=true uv run python -m app.main
# фронт с горячей перезагрузкой, запросы /api проксируются на :8000
cd frontend && npm run dev
# тесты
cd backend && uv run pytest
# новая миграция после изменения моделей
cd backend && uv run alembic revision --autogenerate -m "описание"
```

Документация API: `/api/docs`.

Где что лежит в бэкенде:

| Модуль | Что делает |
|---|---|
| `app/receipts/service.py` | распознавание чеков, каскад, PDF, электронные чеки, траты текстом |
| `app/bank.py` | банковские уведомления, выписки, типы операций и переводы внутри семьи |
| `app/voice.py` | голосовые сообщения |
| `app/products.py` | склейка товаров |
| `app/ask.py` | вопросы и функции, доступные нейросети |
| `app/email_inbox.py` | чеки из почты |
| `app/warranty.py` | напоминания о гарантии |
| `app/reports.py` | месячный отчёт и комментарий |
| `app/llm/` | клиент, промпты и схемы ответов нейросети |
| `app/llm/usage.py` | учёт запросов, балансы провайдеров, предупреждение о низком балансе |
| `app/bot/handlers.py` | бот (перед каждым обработчиком проверяется, что чат семейный) |
| `app/bot/ui.py` | сообщения и кнопки бота, их же используют задачи по расписанию и почта |
| `app/family.py` | поиск члена семьи по имени, карте, почте или имени в банке |
| `app/clock.py` | местное время (`now_local`) |
| `app/constants.py` | виды записей и общие названия |
| `app/api/` | веб-API, по модулю на ресурс (receipts, stats, users, categories, budgets, recurring, llm, ai, auth) |

## Резервная копия

Всё состояние в папке `data/`: база `app.db` и фото чеков. Копию базы можно снять на ходу:

```bash
docker compose exec check-bot python -c "import sqlite3; sqlite3.connect('/app/data/app.db').backup(sqlite3.connect('/app/data/app-backup.db'))"
tar czf backup-$(date +%F).tgz data/
```
