# Семейные расходы

Telegram-бот для семейной группы и веб-интерфейс для учёта расходов.

Купили что-то, сфотографировали чек, отправили в группу. Бот читает QR-код чека, отдаёт фото нейросети, получает список покупок с категориями и записывает в базу. В вебе видно, кто, что, где и на что тратит. Там же оригинал чека для проверки.

## Возможности

- **Распознавание чеков** по фото или файлу, включая HEIC с айфона. Скидки и залог за тару учитываются отдельными строками.
- **Фискальный QR болгарского чека** даёт точные дату и сумму, защищает от повторной записи и помогает выпрямить фото, снятое боком.
- **Сверка сумм.** Если позиции не сходятся с итогом или с QR, чек помечается «Проверить» с объяснением.
- **Запоминание категорий.** Исправили категорию товара в вебе, и она применится к этому товару во всех чеках и будущих покупках.
- **Трата без чека** прямо в группе: `/add такси 12` или `+ кофе 3.50`. Можно одной суммой, `+ 12`, тогда запись попадёт в «Без категории».
- **Трата за другого члена семьи**: `+ Маша: кино 12`, а у фото подпись `Маша: тетради`. Детей без Telegram добавляют в вебе: Настройки → Семья.
- **Описание к чеку**: подпись к фото. Для чека, где только итог, как в овощной лавке, описание становится названием покупки и помогает выбрать категорию.
- **Правка из бота**: ответьте на сообщение бота о записи. Текст станет описанием, число новой суммой, а `Маша:` перенесёт трату на Машу. Кнопка «Удалить» под каждой записью.
- **Правка в вебе**: магазин, дата, итог, описание, кто потратил, позиции и их категории. Удаление записи с подтверждением.
- **Бюджеты по категориям.** Бот предупреждает в группе при 80% и при превышении.
- **Месячный отчёт** с графиком приходит в группу 1-го числа.
- **Регулярные платежи**: аренда, интернет, подписки записываются сами в нужный день.
- **Динамика цен** на одни и те же товары по датам и магазинам.
- **Веб**: статистика по категориям, людям, месяцам и магазинам, список чеков с фильтрами, правка позиций, экспорт в CSV.
- **Только евро.** Если в чеке цены в двух валютах, берутся суммы в евро.

## Стек

| Часть | Технологии |
|---|---|
| Бот | Python 3.13, aiogram 3 |
| Нейросеть | любой OpenAI-совместимый API; по умолчанию DeepSeek через OpenRouter, бесплатные модели как запасные |
| QR | zxing-cpp |
| API | FastAPI, SQLAlchemy 2, Alembic |
| База | SQLite, переезд на PostgreSQL сменой `DATABASE_URL` |
| Фронт | React, Vite, TypeScript, Mantine, TanStack Query, Recharts |
| Запуск | один процесс: веб, бот и планировщик; Docker Compose или systemd |

## Установка

Нужен Docker с Compose. Для запуска без Docker нужны [uv](https://docs.astral.sh/uv/) и Node.js 20 или новее.

### 1. Бот в Telegram

1. В [@BotFather](https://t.me/BotFather) создайте бота командой `/newbot` и сохраните токен.
2. Там же выполните `/setprivacy`, выберите бота и **Disable**. Иначе бот не увидит фото в группе.
3. Добавьте бота в семейную группу и напишите в ней `/chatid`. Бот ответит ID группы. Эта команда работает и до настройки.

### 2. Ключ нейросети

Зарегистрируйтесь на [openrouter.ai](https://openrouter.ai), создайте ключ и пополните баланс на несколько долларов.

Основная модель `deepseek/deepseek-v4.1-flash` платная, но дешёвая: около 0.1 цента за чек, ответ за 5–10 секунд. Бесплатные модели с суффиксом `:free` стоят в списке запасными. Они медленнее и часто упираются в общий лимит провайдера.

Бесплатные модели могут сохранять запросы у провайдера. На фото чека обычно нет ничего личного, но учитывайте это.

### 3. Настройка

```bash
cp .env.example .env
# впишите BOT_TOKEN, ALLOWED_CHAT_IDS, LLM_API_KEY, SECRET_KEY и WEB_PASSWORD
```

### 4. Запуск в Docker

```bash
docker compose up -d --build
```

Веб откроется на `http://адрес-сервера:8000`, порт берётся из `WEB_PORT`. База и фото чеков лежат в папке `data/` рядом с проектом. Миграции базы применяются при старте автоматически.

Полезные команды:

```bash
docker compose logs -f              # логи
docker compose restart              # после правки .env
docker compose up -d --build        # после обновления кода
docker compose down                 # остановить
```

Контейнер перезапускается сам после сбоя и после перезагрузки машины.

### Запуск без Docker

```bash
cd frontend && npm ci && npm run build && cd ..
cd backend && uv sync && uv run python -m app.main
```

Для автозапуска без Docker есть юнит systemd в `deploy/check-bot.service`. Одновременно запускайте что-то одно: два экземпляра бота будут мешать друг другу получать сообщения.

## Вход в веб

- **Через Telegram.** Работает, когда у веба есть домен. В @BotFather выполните `/setdomain` и укажите домен. Пустят только участников группы из `ALLOWED_CHAT_IDS`.
- **По паролю.** Задайте `WEB_PASSWORD`. Подходит, пока домена нет.

Для доступа из интернета поставьте перед сервисом reverse proxy с HTTPS, например Caddy:

```
expenses.example.com {
    reverse_proxy localhost:8000
}
```

## Смена нейросети

Всё задаётся в `.env`, код менять не нужно. Модели перечисляются через запятую. Если первая не ответила или упёрлась в лимит, бот берёт следующую.

```bash
LLM_MODELS=deepseek/deepseek-v4.1-flash,nvidia/nemotron-3.5-super-vl:free,google/gemma-4-31b-it:free
LLM_TEXT_MODELS=deepseek/deepseek-v4-flash
```

Для фото нужна модель, которая принимает изображения. У DeepSeek это только модели с `flash` и поддержкой image. `deepseek-v4-pro` и `deepseek-chat` читают только текст и подходят лишь для `LLM_TEXT_MODELS`.

Список бесплатных моделей, умеющих читать изображения:

```bash
curl -s https://openrouter.ai/api/v1/models | python3 -c "import json,sys; [print(m['id']) for m in json.load(sys.stdin)['data'] if m['id'].endswith(':free') and 'image' in m['architecture']['input_modalities']]"
```

Другие провайдеры, например Gemini напрямую или локальная Ollama, подключаются через `LLM_BASE_URL`. Примеры есть в `.env.example`.

Сравнить модели на своих чеках, ничего не записывая в базу:

```bash
cd backend
uv run python scripts/test_llm.py ~/чек1.jpg ~/чек2.jpg --quiet
uv run python scripts/test_llm.py ~/чек1.jpg --models google/gemma-4-31b-it:free
```

Скрипт показывает время ответа, число позиций и сходится ли сумма с итогом и с QR-кодом.

Чек, распознанный плохо, можно перераспознать в вебе другой моделью кнопкой «Распознать заново».

## Разработка

```bash
# бэкенд без входа и без бота
cd backend && AUTH_DISABLED=true uv run python -m app.main
# фронт с горячей перезагрузкой, запросы /api проксируются на :8000
cd frontend && npm run dev
# тесты
cd backend && uv run pytest
# новая миграция после изменения моделей
cd backend && uv run alembic revision --autogenerate -m "описание"
```

Документация API: `/api/docs`.

## Резервная копия

Всё состояние в папке `data/`: база `app.db` и фото чеков. Достаточно копировать её, например так:

```bash
sqlite3 data/app.db ".backup data/app-backup.db" && tar czf backup-$(date +%F).tgz data/
```
